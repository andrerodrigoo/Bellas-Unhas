# Bellas-Unhas

Website profissional desenvolvido para um estúdio de manicure, criado para fortalecer a presença digital da empresa e facilitar o contato com novos clientes.

O projeto foi desenvolvido com foco em experiência do usuário, design moderno, responsividade e conversão, permitindo que os visitantes conheçam os serviços oferecidos e realizem o agendamento diretamente pelo WhatsApp.

## Funcionalidades

- Design moderno e responsivo
- Portfólio de trabalhos realizados
- Informações sobre os serviços
- Integração direta com WhatsApp
- Navegação intuitiva
- Otimização para dispositivos móveis
- SEO básico
- Alto desempenho

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Netlify

## Processo de Desenvolvimento

Este projeto foi desenvolvido utilizando um fluxo de desenvolvimento assistido por Inteligência Artificial.

Todo o planejamento, definição das funcionalidades, criação dos prompts, organização da interface, testes, ajustes e publicação do projeto foram conduzidos por mim, utilizando a IA como ferramenta de apoio para acelerar o desenvolvimento e refinar a solução entregue ao cliente.
